# Anti-Slop Design: The Human-Grade UI/UX Engineering Skill

> **Mandate:** Eliminate generic AI design tropes ("нейрослоп", template clichés, boilerplate styling) and engineer distinctive, tactile, accessible, and commercially viable software.

## 1. The Anti-Slop Banned Matrix
1. **The 'AI Dark Mode' Blob**: Banned generic purple/indigo blur blobs. Mandatory replacement: Deep monochrome titanium surfaces (`#06080E`, `#0B0F19`) with subtle 1px hairline borders (`rgba(255,255,255,0.08)`).
2. **Raw Emojis as Icons**: Strictly forbidden. Use crisp SVG vector icons (Lucide, Phosphor) with 1.5px/2px stroke width.
3. **Tabular Numerics**: Always enforce `font-variant-numeric: tabular-nums` and monospace fonts for currency, coordinates, and telemetry.
4. **1-to-3 Rule**: 1 primary focal CTA, max 3 secondary actions per card/container.
